Flow 5 — Files + Frames E2E (Lebyy Practice Lab)
====================================================

Covers Video 6 (Files + Frames)

Practice goal
-------------
Automate file upload (single + multi), file download assertions, iframe interactions
(single, multiple, nested), and multi-tab / popup handling using Playwright.

Try these flows yourself before watching the video. In the video I will show the Cursor prompt,
walk through the generated script, run it, and attach the final spec file.

Style note
----------
- Separate test() block for each scenario
- Each test starts with page.goto(...)
- Use page.frameLocator(...) to interact inside iframes
- Use page.waitForEvent('download') before clicking download links
- Use context.waitForEvent('page') before clicking multi-tab buttons
- Same simple style as other course specs

File flows (3 E2E tests)
------------------------

Test 1 — Single file upload attaches successfully  [UPLOAD]
------------------------------------------------------------
test('Single file upload attaches successfully', async ({ page }) => {

1. page.goto('https://lebyy.com/practice/attachments.html')

2. Assert selected name → "No file selected"

3. Set file on single input → tests/fixtures/evidence.txt
   (page.getByTestId('file-input').setInputFiles('tests/fixtures/evidence.txt'))

4. Assert selected name → contains "evidence.txt"

5. Click Attach file

6. Assert upload alert → contains "Attached locally: evidence.txt"

})


Test 2 — Multi-file upload attaches all files  [MULTI UPLOAD]
---------------------------------------------------------------
test('Multi-file upload attaches all files', async ({ page }) => {

1. page.goto('https://lebyy.com/practice/attachments.html')

2. Set files on multi input → report-a.txt + report-b.csv

3. Assert selected multi names → contains "report-a.txt" and "report-b.csv"

4. Click Attach files

5. Assert multi upload alert → contains "Attached locally:"
   - contains "report-a.txt"
   - contains "report-b.csv"

})


Test 3 — Download TXT file with correct name and content  [DOWNLOAD]
--------------------------------------------------------------------
test('Download TXT file with correct name and content', async ({ page }) => {

1. page.goto('https://lebyy.com/practice/attachments.html')

2. Start waiting for download BEFORE click:
   const downloadPromise = page.waitForEvent('download')

3. Click Download TXT

4. Resolve download and assert:
   - download.suggestedFilename() → "lebyy-sample-evidence.txt"
   - saved file content → contains "Sample evidence file for Lebyy Practice Lab downloads."

})

Frame flows (3 E2E tests — iframe + nested + multi-tab)
-------------------------------------------------------

Test 4 — Single iframe button completes action  [IFRAME]
--------------------------------------------------------
test('Single iframe button completes action', async ({ page }) => {

1. page.goto('https://lebyy.com/practice/frames.html')

2. Use frameLocator on single iframe:
   const frame = page.frameLocator('[data-testid="lab-iframe"]')

3. Assert frame heading → "Inside the iframe"

4. Assert frame status → "Waiting…"

5. Click Mark frame ready (inside frame)

6. Assert frame status → "Frame action completed"

})


Test 5 — Nested frame saves typed value  [NESTED IFRAME]
--------------------------------------------------------
test('Nested frame saves typed value', async ({ page }) => {

1. page.goto('https://lebyy.com/practice/frames.html')

2. Chain frameLocators for nested frames:
   const nestedChild = page
     .frameLocator('[data-testid="frame-nested-parent"]')
     .frameLocator('[data-testid="frame-nested-child"]')

3. Assert nested child heading → "Nested child frame"

4. Fill nested child input → "regression-suite"

5. Click Save nested value (inside nested child)

6. Assert nested child status → contains "Saved: regression-suite"

})


Test 6 — Helper tab opens with correct title  [MULTI-TAB]
---------------------------------------------------------
test('Helper tab opens with correct title', async ({ page, context }) => {

1. page.goto('https://lebyy.com/practice/frames.html')

2. Start waiting for new page BEFORE click:
   const pagePromise = context.waitForEvent('page')

3. Click Open helper tab

4. Resolve new page (helper tab)

5. Wait for helper page to load

6. Assert helper page title → "Lebyy Lab Helper"

7. Assert helper title heading → "Lebyy Lab Helper"

8. Assert helper body → contains "multi-tab automation practice"

9. Assert parent window note → contains "Helper tab opened"

10. Close helper tab

})
